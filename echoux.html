    This portfolio project showcases the homepage of a fictional User Experience Design website called “Echo UX”, inspired by the homepage of Spinx. The structure was built with HTML5, while the visual design was created with CSS. All clickable elements feature hover or click interactions implemented with CSS.

    Note: This project is designed for desktop devices.
